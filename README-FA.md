# Koochebagh — Template Adaptation v1
این نسخه مستقیماً بر پایه صفحه Bali از قالب Travel_destination_landing-page ساخته شده است.

## مشاهده
فایل index.html را باز کنید.

## تغییرات انجام‌شده
- فارسی و RTL
- Vazirmatn
- لوگوی رسمی کوچه‌باغ
- تبدیل ساختار Travel به Koochebagh
- بخش‌های کشف شهرستان، خدمات، امروز و پردیس
- حذف منطق رزرو و قیمت‌گذاری

## مهم
تصاویر Bali در این مرحله عمداً به‌عنوان Placeholder قالب حفظ شده‌اند. مرحله بعد، جایگزینی با تصاویر واقعی طرقبه شاندیز است.


## تغییرات V2
- عنوان اصلی Hero با فونت نمایشی Lalezar و رنگ سفید
- تصاویر بخش‌های اصلی با تصاویر واقعی مرتبط با شاندیز، کنگ و شهرستان طرقبه‌شاندیز از Wikimedia Commons جایگزین شده‌اند.
- تصاویر به صورت اینترنتی بارگذاری می‌شوند و برای نمایش آن‌ها اتصال اینترنت لازم است.
