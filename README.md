# Koochebagh Landing Page

Landing page for Koochebagh / Torghabeh-Shandiz County.

## GitHub Pages
Publish from the repository root on the `main` branch. `index.html` is the entry page. A custom `404.html` and `.nojekyll` are included.

## Custom domain
Set the custom domain from **Settings → Pages** after the repository is published. Do not add a `CNAME` file until the final domain is known.
